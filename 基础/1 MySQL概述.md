### 一、数据库相关概念

| 名称      | 全称                              | 简称   |
| ------- | ------------------------------- | ---- |
| 数据库     | 存储数据的仓库，数据是有组织的进行存储             | DB   |
| 数据库管理系统 | 操作和管理数据库的大型软件                   | DBMS |
| SQL     | 操作关系型数据库的编程语言，定义了一套操作关系型数据库统一标准 | SQL  |

### 二、MySQL启动与停止
  命令行操作：
    启动：net start mysql80
    停止：net stop mysql80
  服务管理器操作：
     1.win+R
     2.输入services.msc
     3.找到MySQL80
     4.停止或启动

### 四、数据模型
  （一）关系型数据库
    概念：建立在关系模型基础上，由多张相互连接的二位表组成的数据库
    特点：
      1.使用表存储数据，格式统一，便于维护
      2.使用SQL语言操作，标准统一，使用方便
