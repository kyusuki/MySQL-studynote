`application.yaml`是`Spring Boot`项目的主配置文件，`db.properties`是自定义的`.properties`配置文件


配置`application.yaml`，`Spring Boot`启动时会自动加载，自动创建数据源、连接池，可不再手动写`DBHelper`类
```
spring:
  application:
    name: 项目名
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/表名?useUnicode=true&characterEncoding=utf8&autoReconnectForPools=true&useSSL=false
    username: root
    password: 666666
    driver-class-name: com.mysql.cj.jdbc.Driver
```


配置`db.properties`，传统手动读取配置方式
```
db.driver=com.mysql.cj.jdbc.Driver
db.url=jdbc:mysql://localhost:3306/book?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf-8
db.username=root
db.password=666666
```
