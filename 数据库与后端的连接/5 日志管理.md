`Spring Boot`自动继承日志框架，无需再通过`pom.xml`注入依赖

1.手动注入依赖
```
<dependency> 
    <groupId>org.springframework.boot</groupId> 
    <artifactId>spring-boot-starter-logging</artifactId> 
</dependency>
```

2.配置日志管理的`logback.xml`，告诉程序怎么打印日志
```
<?xml version="1.0" encoding="UTF-8"?>  
<configuration>  
    <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">  
        <encoder>            
            <pattern>%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>  
        </encoder>    
    </appender>  
    
    <appender name="FILE" class="ch.qos.logback.core.rolling.RollingFileAppender">  
        <file>logs/library.log</file>  
        <encoder>            
            <pattern>%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level %logger{36} - %msg%n</pattern>  
            <charset>UTF-8</charset>  
        </encoder>        
        <rollingPolicy class="ch.qos.logback.core.rolling.SizeAndTimeBasedRollingPolicy">  
            <fileNamePattern>logs/library-%d{yyyy-MM-dd}.%i.log</fileNamePattern>  
            <maxFileSize>10MB</maxFileSize>  
            <maxHistory>30</maxHistory>  
            <totalSizeCap>500MB</totalSizeCap>  
        </rollingPolicy>    
        </appender>  
    
    <root level="INFO">  
        <appender-ref ref="CONSOLE" />  
        <appender-ref ref="FILE" />  
    </root>
</configuration>
```

3.程序中导包，使用`slf4j`管理日志
```
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
```

4.程序中调用
```
private static final Logger log=LoggerFactory.getLogger(此程序类名.class);
```

5.日志打印方法
```
log.trace("xxx")
  功能：最细的跟踪信息，检测每一步执行到哪了
  场景：调试极深逻辑、循环细节、方法进出
  
log.debug("xxx")
  功能：调试信息
  场景：开发时看变量值、流程走到哪
  
log.info("xxx")
  功能：程序正常运行的关键信息
  场景：程序启动成功、接口被调用、任务开始/结束、正常业务记录
  
log.warn("xxx")
  功能：不影响运行，只是作用于警告
  场景：参数为空但不报错、查询结果为空、调用慢但程序没崩、配置不规范等等
  
log.error("xxx")
  功能：程序出错、异常、业务失败、数据库报错
  场景：catch里打印日志、数据库失败、接口报错、业务无法继续
```
